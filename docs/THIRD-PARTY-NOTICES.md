# Spring Security default UI

`public/default-ui.css` was copied without changes from the locally installed `spring-security-web-7.1.0.jar`, resource `org/springframework/security/default-ui.css`.

The login/logout markup in `src/pages/login.tsx` and `src/pages/logout.tsx` was adapted from the default screens generated by that same library, retaining the original appearance and labels. Changes: React syntax, Next.js routing, CSRF token and safe return path handling.
